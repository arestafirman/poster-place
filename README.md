A travel poster for a place that isn't there: **LUMARIS**, the bay that glows
at night. A slim white lighthouse on a rocky cape, a cyan-glowing bay at
indigo dusk, one small lantern-lit boat on the water.

## Run

```sh
python3 main.py
```

Writes `entry.png` (1024×1024, ≤1 MiB) to `$MAKEFUN_OUTPUT_DIR`
(fallback `/output`). Pure stdlib + PIL, deterministic — run it twice and
the bytes are identical.
